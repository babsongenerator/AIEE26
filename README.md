# AIEE26: Build 1 workshop

This repository holds the starters and guides for Build 1: From Concept to Prototype with AI, at AI for Entrepreneurship Educators 2026 (Babson Academy and the Generator). Jonathan Sims and Jonathan Griffiths lead the session.

You pick one of three tracks and build a working tool for a class you teach. Each track has a folder here.

| Track | Folder | What you build | Where you work |
|---|---|---|---|
| Make a Game | `make-a-game` | Launch Day, a startup market game, rewritten around a case you teach | Claude Code |
| Make a Class Tool | `make-a-class-tool` | A name-practice page for an invented class, then a tool of your own | Claude Code |
| Make a Prototype | `make-a-prototype` | A physical object you design with AI and 3D print at the Weissman Foundry | Claude |

Nothing needs to be installed. Every starter is a set of plain web pages that open with a double-click.

## Start in the Claude desktop app (recommended)

1. Make a new, empty folder on your computer, for example `aiee-build` on your Desktop.
2. Open the Claude desktop app, click Code, and choose that folder.
3. Copy your track's first prompt below, fill in the parts in square brackets, and paste it in.
4. Answer Claude's questions. When you like its plan, type go.

### Make a Game

> I teach [course] to [who your students are]. Download https://github.com/babsongenerator/AIEE26/archive/refs/heads/main.zip, unzip it in this folder, and keep only the make-a-game folder. Then read make-a-game/CLAUDE.md. I want Launch Day to run on a case from my class: [the company, its market, and its rivals]. Ask me up to three short questions about the case, one at a time. Then propose a plan in five steps or fewer. Do not change anything until I say go.

### Make a Class Tool

> I teach [course] to [who your students are]. Download https://github.com/babsongenerator/AIEE26/archive/refs/heads/main.zip, unzip it in this folder, and keep only the make-a-class-tool folder. Then read make-a-class-tool/CLAUDE.md. I want a name-practice page for this class: show a face, let me guess the name, then reveal it, and keep track of the names I miss. Ask me up to three short questions about how I would use it, one at a time. Then propose a plan in five steps or fewer. Do not write any code until I say go.

### Make a Prototype

This track works in a regular Claude chat. Open `make-a-prototype/README.md` for its first prompt and Jonathan Griffiths's guide.

## Start in Claude on the web

If you only have Claude in a browser, you can still build the same tools as artifacts, the pages Claude makes inside a chat.

1. Download your track's starter file: `make-a-game/index.html`, or `make-a-class-tool/index.html` and `make-a-class-tool/students.js`. On GitHub, open the file and click the download button.
2. Start a new chat at claude.ai and attach the file.
3. Paste your track's first prompt from above, and replace the download sentence with this one: "I attached the starter. Give me the finished page as an artifact I can try here."

The web path leaves out the student portraits, so the class tool shows initials in their place.

## Privacy

Use the invented class and made-up student work only. The 20 students in `make-a-class-tool` are invented, and their portraits were made with AI.

## After the session

- `make-a-game/GO-FURTHER.md` shows how to run the full Launch Day, where players join from their phones and Claude judges each bold move.
- Everything here stays available after the workshop, so you can come back and keep building.
